## Residual Sublation Layer v0.1.0

First public release of a dual-signal residual decision module with hidden parity.

### Included

- `residual_sublation.h` — minimal C11/C++ header
- `rsl_senility_harness.py` — empirical separation harness
- `RSL_DESIGN_NOTE.md` — design note with non-reducibility argument and intellectual lineage

### Guarantees at this version

- Non-reducibility to residual + confidence + hysteresis (hidden parity argument)
- Documented separation on a recoverable senility schedule (dual-active window + lower cumulative residual error)
- Sketch residual potential under the elevated regime

### Explicit non-claims

- Not production-hardened
- Limited baseline set
- Parameters not exhaustively tuned
- Does not replace existing residual menus; it is an optional elevation layer
